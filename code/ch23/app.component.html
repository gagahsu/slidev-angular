🗄️ 網頁儲存示範

① localStorage（永久儲存）

關掉瀏覽器再開，資料還在。

讀取結果：{{ localReadResult }}

localStorage.setItem('key', 'value') / getItem('key')

② sessionStorage（分頁關掉就消失）

同一個分頁內有效，關掉分頁就清除。

讀取結果：{{ sessionReadResult }}

sessionStorage.setItem('key', 'value') / getItem('key')

③ 儲存物件（JSON.stringify / JSON.parse）

儲存只能存字串，物件需要先轉換。

讀取結果：{{ objectReadResult }}

// 存：localStorage.setItem('key', JSON.stringify(物件))
// 取：JSON.parse(localStorage.getItem('key'))

📊 三種儲存方式比較

方式 容量 存活時間 常用情境
Cookie ~4KB 可設定過期時間 登入 token
localStorage ~5-10MB 永久（手動清除） 使用者偏好設定
sessionStorage ~5-10MB 關閉分頁即清除 表單暫存
