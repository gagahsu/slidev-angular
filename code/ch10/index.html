⑥ Bootstrap 快速說明

Bootstrap 是業界最流行的 CSS 框架，提供大量現成的樣式和元件。 不用自己寫一堆 CSS，只要加上特定的 class 名稱，就能套用漂亮的設計！

安裝方式

在 Angular 專案中安裝：

npm install bootstrap

在 angular.json 裡加入：

"styles": [
  "node_modules/bootstrap/dist/css/bootstrap.min.css",
  "src/styles.css"
]

Bootstrap 常用 Class

  • d-flex → 相當於 display: flex
  • justify-content-center → justify-content: center
  • align-items-center → align-items: center
  • btn btn-primary → 藍色按鈕
  • card → 卡片樣式
  • container → 置中容器（加上最大寬度）
