📑 Tabs 頁籤示範

① mat-tab-group（靜態內容）

切換頁籤不改 URL，適合頁面內的區塊切換。

第一頁的內容

這裡可以放任何 HTML 元素，包括表格、表單、圖片等。

第二頁的內容

切換到這裡時，第一頁的內容不會消失（只是被隱藏）。

第三頁的內容

mat-tab-group 支援任意數量的頁籤。
這個頁籤無法被選取。

② 用 @for 動態產生頁籤

頁籤資料來自 TypeScript 陣列，方便動態新增。

@for (tab of staticTabs; track tab.label) {

{{ tab.content }}

 }

③ mat-tab-nav-bar（路由頁籤）

搭配 routerLink 使用，切換頁籤會改變 URL。

@for (link of links; track link.path) { {{ link.name }} }
⚠️ mat-tab-nav-bar 需要配合 app.routes.ts 設定路由才能正常運作。 這個範例示範程式碼結構，實際使用時請搭配路由設定。
