📊 Chart.js 圖表示範

安裝指令

npm install chart.js

然後在 TypeScript 裡 import Chart from 'chart.js/auto'

① 圓餅圖（pie）— 月支出分配

new Chart(canvas, { type: 'pie', data: data })

② 長條圖（bar）— 每月收入

new Chart(canvas, { type: 'bar', data: data })

📋 常用圖表類型

type 值 圖表類型 適合情境
'pie' 圓餅圖 佔比分析
'doughnut' 甜甜圈圖 佔比分析（有中心空間）
'bar' 長條圖 數量比較
'line' 折線圖 趨勢變化
