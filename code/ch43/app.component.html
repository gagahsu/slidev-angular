⏱️ 同步 vs 非同步示範

核心概念

同步（Sync）

排隊等候，一個完成才做下一個。
順序：A → B → C

非同步（Async）

叫號系統，不等待，繼續做其他事。
順序：A → C → B（B 後來才回來）

① 同步執行順序

@for (log of syncLog; track $index) {
{{ $index + 1 }}. {{ log }}
}

→ 按照程式碼順序一行一行執行，完全可預測

② 非同步執行（setTimeout 2秒後）

@for (log of asyncLog; track $index) {
{{ $index + 1 }}. {{ log }}
}

→ ① 和 ② 立刻出現，頁面開啟 2 秒後 ③ 才出現

③ Observable + subscribe（HTTP 請求）

@if (isLoading) {
⏳ 等待 API 回應（非同步，不阻塞其他操作）...
} @if (errorMsg) {
❌ {{ errorMsg }}
} @if (apiData) {
✅ 資料回來了： 
{{ apiData | json }}
}

subscribe() 三個 callback

this.http.get(url).subscribe({
  next:     (data) => { /* 資料回來時執行 */ },
  error:    (err)  => { /* 發生錯誤時執行 */ },
  complete: ()     => { /* 所有資料傳完時執行 */ }
});
