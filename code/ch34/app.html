📅 日期選擇器示範

① 原生 HTML <input type="date">

瀏覽器內建的日期選擇，不需要額外安裝套件。

選取的值：{{ nativeDate }}

格式：YYYY-MM-DD 字串，可直接存進 DB

其他 type 變體：

② Angular Material mat-datepicker

美觀的月曆 UI，直接綁定 Date 物件，支援 min / max 限制。

選擇日期 限制範圍：2024/11/01 ~ 2024/12/31

選取的值：{{ formattedDate }}

TypeScript 中是 Date 物件，可直接使用 getFullYear()、getMonth() 等方法。
