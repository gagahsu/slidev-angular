⑤ Box Model（盒子模型）

常用 CSS 單位

  • px：像素，固定大小（例：font-size: 16px）
  • %：相對於父元素的百分比（例：width: 50%）
  • rem：相對於根元素 html 的大小（例：1rem = 16px）
  • em：相對於當前元素的字體大小
