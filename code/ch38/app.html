🎨 ngClass 動態 CSS 類別

① 物件條件 { 'class名': 條件 }



這個方塊的 class 由上方 checkbox 控制
[ngClass]="{ 'active': isActive, 'danger': isDanger }"

② 實際應用 — 頁籤選中狀態

@for (tab of ['home', 'profile', 'settings']; track tab) { }
目前頁籤：{{ activeTab }}
[ngClass]="{ 'tab-active': activeTab === tab }"

③ 方法回傳 — 庫存狀態

當 class 判斷邏輯複雜時，把邏輯寫在 TypeScript 方法裡。

@for (item of items; track item.name) { }
商品 庫存 狀態 選取
{{ item.name }} {{ item.stock }} @switch (getStatusClass(item.stock)) { @case ('in-stock') { ✅ 庫存充足 } @case ('low-stock') { ⚠️ 庫存不足 } @case ('out-of-stock') { ❌ 無庫存 } } @if (item.selected) { ☑️ } @else { ☐ }
[ngClass]="getStatusClass(item.stock)"   ← 方法回傳 class 名稱字串
