💬 Dialog 對話框示範

使用流程

  1. 建立 dialog 元件（dialog.component.ts + html）
  2. 父元件 inject MatDialog
  3. 呼叫 this.dialog.open(DialogComponent, { data, width })
  4. 透過 afterClosed().subscribe() 接收回傳值

① 基本 Dialog（傳入 data）

打開 dialog 並傳入 title / message / userName。

@if (dialogResult !== null) {
Dialog 回傳值： {{ dialogResult | json }}
}

② 確認 Dialog（disableClose）

設定 disableClose: true，點擊背景不會關閉。

@if (confirmResult) {
結果： {{ confirmResult }}
}

關鍵程式碼

// 打開 dialog
const dialogRef = this.dialog.open(DialogComponent, {
  data: { title: '標題', message: '訊息' },
  width: '450px'
});

// 接收回傳值
dialogRef.afterClosed().subscribe(result => {
  console.log('回傳：', result);
});
