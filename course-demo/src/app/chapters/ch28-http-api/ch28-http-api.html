🌐 串接 API

① 如何使用 API

  1. 在 app.config.ts 加入 provideHttpClient()
  2. 建立 HttpClientService，封裝四種 HTTP 方法
  3. 在元件注入 Service，並用 subscribe 接收結果

進入這一頁時已經呼叫 GET API，打開 F12 → Console 可以看到結果
