① 基本 @if / @else — 登入狀態

@if (isLoggedIn) {
✅ 已登入！歡迎回來，會員！
} @else {
🔒 請先登入才能查看內容。
}

② @else if — 成績等級


@if (score >= 90) {
🌟 優秀！（90 分以上）
} @else if (score >= 60) {
✅ 及格（60-89 分）
} @else {
❌ 不及格（60 分以下），加油！
}
