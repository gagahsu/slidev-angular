📆 DatePipe 日期格式化

❌ 未格式化（原始 Date 物件）

直接用插值輸出 Date 物件，結果難以閱讀：

{{ today }}

這不是給使用者看的格式...

🔧 手動格式化（TypeScript 方法）

用 getFullYear() / getMonth() / getDate() 自己組字串：

日期：{{ tidyDate(today) }}

日期時間：{{ tidyDateTime(today) }}

→ 可以做到，但程式碼冗長（要處理補零邏輯）

✅ DatePipe（一行搞定）

語法：{{ '{{' }} 日期 | date: '格式字串' {{ '}}' }}

格式字串 輸出結果
'yyyy/MM/dd' {{ sampleDate | date: 'yyyy/MM/dd' }}
'yyyy-MM-dd' {{ sampleDate | date: 'yyyy-MM-dd' }}
'MM/dd/yyyy' {{ sampleDate | date: 'MM/dd/yyyy' }}
'yyyy/MM/dd HH:mm:ss' {{ today | date: 'yyyy/MM/dd HH:mm:ss' }}
'fullDate' {{ sampleDate | date: 'fullDate' }}
'shortDate' {{ sampleDate | date: 'shortDate' }}
