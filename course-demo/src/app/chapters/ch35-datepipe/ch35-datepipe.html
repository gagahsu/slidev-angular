📆 DatePipe 日期格式化

① 直接顯示 Date 物件（原始格式）

{{ today }}

② 方法一：提取年、月、日

getFullYear()：{{ today.getFullYear() }}

getMonth()：{{ today.getMonth() }}（從 0 起算，實際月份要 +1）

getDate()：{{ today.getDate() }}

③ 方法一：呼叫 tidyDate()

{{ tidyDate(today) }}

{{ '{{' }} tidyDate(today) {{ '}}' }}

④ 方法二：DatePipe

{{ today | date: 'yyyy-MM-dd' }}

{{ '{{' }} today | date: 'yyyy-MM-dd' {{ '}}' }}
格式字串 輸出結果
'yyyy/MM/dd' {{ today | date: 'yyyy/MM/dd' }}
'yyyy-MM-dd' {{ today | date: 'yyyy-MM-dd' }}
'MM/dd/yyyy' {{ today | date: 'MM/dd/yyyy' }}
'fullDate' {{ today | date: 'fullDate' }}
'shortDate' {{ today | date: 'shortDate' }}
