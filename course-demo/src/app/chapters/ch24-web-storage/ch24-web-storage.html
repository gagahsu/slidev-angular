🗄️ 網頁儲存

① 網頁儲存的三種方法

方式容量主要用途
Cookie約 4KB登入、跨域 Tracking、Session ID
localStorage約 5–10MB自訂資料，手動清除才消失
sessionStorage約 5–10MB自訂資料，分頁關閉即消失

② Cookie 小節練習（需安裝 ngx-cookie-service）

這個示範專案沒有安裝 ngx-cookie-service，這裡只列出投影片的程式碼

// login.component.ts
cookieService = inject(CookieService);
onLoginSuccess() { this.cookieService.set('theme', 'dark', 30); }

// dashboard.component.ts
cookieService = inject(CookieService);
constructor() { console.log(this.cookieService.get('theme')); }
