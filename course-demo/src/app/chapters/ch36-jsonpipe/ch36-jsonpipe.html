🔍 JsonPipe 物件格式化

❌ 直接插值物件（問題）

直接用 {{ '{{' }} user {{ '}}' }} 顯示物件：

{{ user }}

← 看到 "[object Object]"，沒有任何有用的資訊

✅ 加上 json Pipe

用 {{ '{{' }} user | json {{ '}}' }}：

{{ user | json }}

✅✅ 搭配 <pre> 標籤（最佳解）

用 <pre>{{ '{{' }} user | json {{ '}}' }}</pre>：

{{ user | json }}

{{ order | json }}

{{ scores | json }}
