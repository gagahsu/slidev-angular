路由核心概念

app.routes.ts

定義 URL 路徑 → 元件的對應關係

<router-outlet>

路由切換的「插槽」，Angular 把對應元件放在這裡

routerLink

替代 href，點擊後切換路由不重新載入頁面

ActivatedRoute

讀取目前路由的參數，例如 /courses/:id 的 id 值

本專案的路由設定（app.routes.ts）

{ path: 'ch14', loadComponent: () => import('./ch14-variables')... }

{ path: 'ch15', loadComponent: () => import('./ch15-methods')... }

{ path: 'ch17', loadComponent: () => import('./ch17-data-design')... }

... 其餘章節以此類推

側邊欄的每個連結就是一個 routerLink，點擊後更換 <router-outlet> 的內容
